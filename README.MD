# 🐦 Aviario

**Sistema integral de gestión de aves y reproducción**

> [!IMPORTANT]
> 🚧 **Estado: En desarrollo — Fase inicial**
>
> Aviario se encuentra actualmente en construcción. Su arquitectura, funcionalidades y documentación están sujetas a cambios.
>
> El desarrollo será progresivo, comenzando por el módulo de **Jaulas** y ampliándose posteriormente con la gestión de aves, reproducción, genealogía y cuidados.

## Sobre el proyecto

Aviario es una aplicación web de código abierto orientada a la gestión de aviarios y al seguimiento de aves y sus procesos reproductivos.

Aunque inicialmente está pensado para canarios, su diseño buscará admitir cualquier especie de ave.

## Tecnologías previstas

- **Frontend:** React + TypeScript
- **Backend:** PHP + API REST
- **Base de datos:** MySQL
- **Infraestructura:** Docker Compose
